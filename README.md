## YouTube Speed Controls

**YouTube Speed Controls is a Google Chrome Extension, the original can be found [here](https://chrome.google.com/webstore/detail/youtube-speed-controls/naalfmaaomhjpbndelnlijacdniggpjn).**

## Overview

Click <code>&#96;</code> (the grave accent key) to increase speed by 0.5x increments, or <code>ctrl + &#96;</code> to decrease speed by 0.5x increments.
The minimum playback speed is 0.5x and the maximum is 4x.
